# ADNU Trade Login

1. Install Node.js (https://nodejs.org)
2. In VS Code: File > Open Folder > adnu-trade-login
3. Terminal > New Terminal, then run:
   npm install
   npm run dev
4. Open the link shown (http://localhost:5173)
